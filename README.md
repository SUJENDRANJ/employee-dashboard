# Employee Index — Employee Management Dashboard

A full-stack Employee Management Dashboard built with React, Tailwind CSS, and json-server. It provides employee CRUD operations, dashboard analytics, authentication, search, filtering, pagination, charts, and dark mode.

---

## Features

- Login with protected routes
- Employee CRUD (Add, Edit, Delete)
- Dashboard analytics
- Search and filtering
- Department filter
- Pagination
- Bar and Pie charts
- Toast notifications
- Light/Dark mode
- Responsive design
- Loading, empty, and error states

---

## Tech Stack

- React 18
- Vite
- React Router DOM
- Redux-toolkit
- Tailwind CSS
- Axios
- Recharts
- mockAPI

---

## Installation

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Frontend:
http://localhost:5173
